## 开拍前 3 步（90 秒能做完）

1. **数据摆好**（当前库已经是这个状态，重启过就再跑一次）：
   ```bash
   cd C:/Users/Y7000P/WorkBuddy/2026-10-28-16-31-40
   /c/Users/Y7000P/.workbuddy/binaries/python/envs/default/Scripts/python scripts/seed_test.py --scene alert
   ```
   期望画面：**5 条日程（全部在今晚到明早之间）、没有「进行中」**；
   时间轴亮一条琥珀带，标题行右侧「撞车 1」（可能还有「太紧 1」，按画面上的数念）；
   宠物是**警觉**。

   > 轴会停在**有冲突的那一天**，标题如实写「今天 / 明天 / 日期」。seed 的时间是
   > 「现在 + 几小时」生成的：**21 点前跑**，冲突都在今天，标题是「今天的时间分布」；
   > **21 点后跑**，冲突自然滑到次日凌晨，标题变成「明天的时间分布」——这是对的，
   > 照念「时间轴」就行，别念「今天」。想拍「今天」就白天跑 seed。

2. **服务起来**（两个窗口都在跑就跳过）：后端 `127.0.0.1:8000`、前端 `127.0.0.1:5173`。

3. **确认这次真在调模型**：点一次「问决策器」，等卡片出来看左上角角标——
   紫的「模型建议」才是真模型；橙的「规则兜底」说明 Key 或网络有问题，这时不要开拍。

> ⚠️ **别预演「采用」**。采纳一次，撞车就被解掉，开头那段警觉态、那条琥珀带、那句
> 「撞车 1」全部消失，只能重跑一遍 seed。要练手就练点按钮和等待，不要点「采用」。
>
> ⚠️ **别在正式拍摄前把「不再提醒这类」点够三次**。一旦这类建议被降权，
> 后面就再也问不出紫色卡片了，第六章的兜底镜头也拍不到对照。要重置就重跑 seed。
>
> ⚠️ **开场别挂着一张旧卡**。每跑一次 seed，记录 ID 全换，之前那张干预卡就会变成
> 「该日程已不存在」。看到它就点卡片右上角的「收起」；想彻底干净就先备份再删：
> ```bash
> cp data/app.db data/backups/before-shoot-$(date +%H%M%S).db
> /c/Users/Y7000P/.workbuddy/binaries/python/envs/default/Scripts/python -c "import sqlite3;c=sqlite3.connect('data/app.db');c.execute('delete from interventions');c.commit()"
> ```

> 拍摄技法：关灯、F11 全屏、浏览器缩放 110%、窗口设成 1560×1000。
> 光流那 1 秒和换档扫光，后期放慢到 0.3 倍比实时好看。
